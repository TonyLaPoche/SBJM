# S.J Delacombaz

Site vitrine et réservation de cours de batterie à distance pour [Sebastien J. Delacombaz](https://www.sebastiendelacombaz.com/).

## Stack

- Next.js (App Router)
- next-intl (anglais / français)
- Tailwind CSS

## Développement

```bash
npm install
npm run dev
```

Le site est servi sur [http://localhost:3000](http://localhost:3000). La version française est sur `/fr`.

## Contenu repris du site actuel

- Biographie, mentors et formation
- Vidéo FI:LDS — Live at Bimhuis
- Quatre compositions originales (Shift, Ghost Light, Across, Untitled 1)
- Portrait et coordonnées

## Variables d’environnement

Voir `.env.example`. `NEXT_PUBLIC_SITE_URL` sert au SEO, au sitemap et aux Open Graph.
